# CLI 开发规范

> 红线 + 最低要求。交付物 = **CLI + 同仓 `SKILL.md`**。代码怎么写 → 各仓 `AGENTS.md`（参照 [horae-api](https://code.gf.com.cn/gf/_code/gf/gzcaoxin/horae-api)）。

---

## 红线（安全）

- 不硬编码 Cookie、Token、密码——凭据走环境变量
- 凭据不进日志、不进命令输出
- 无凭据时明确报错，不静默失败
- **默认只读**；写操作（create / submit / delete）独立子命令，README 标 ⚠️ 有副作用、执行前需确认

---

## 要求（输入输出清楚）

- 一条命令干一件事；入参、出参格式稳定，同类命令风格一致
- 失败说人话（原因 + 下一步），成功 `0`、失败非 `0`
- UTF-8，中文不乱码
- README 每个子命令写清：入参、出参、示例
- **网络调用有超时**——超时报清楚，别挂死整轮对话
- **列表默认限量**——避免一次输出几千行撑爆 Agent 上下文
- **`--help` / `--version` 可用**，help 里带可复制示例

---

## CLI 层 SKILL.md（跟 CLI 同仓，必须写清楚）

工具型 Skill = 这个 CLI 的「用法说明书」，和命令强绑定，**跟 CLI 放同一仓库**：

```
horae-api/
├── horae/              # CLI
└── skills/horae/
    └── SKILL.md        # 工具 Skill（目录名随意）
```

**红线（跟 CLI 一致）**

- 不写 Cookie/Token/密码，不写 `/bin/horae`、`C:/Users/...` 等路径——只写命令名 `horae`
- ✅能 / ❌不能 与 CLI README 一致；写操作标 ⚠️ 需用户确认

**必须写清楚（Agent 靠这个选对命令）**

| 块 | 写什么 |
|----|--------|
| `description` | 做什么 + 触发词（中英口语）；和场景 Skill 易混时写一句边界 |
| **用户说法 → 命令** | 「搜表」「查血缘」「看日志」各对应哪条命令、关键参数 |
| **Commands** | 命令表：命令 / 用途 / 关键参数 |
| **权限边界** | ✅能 / ❌不能 / 写操作需确认 |
| **常见错误** | 认证失败、空结果、参数不对——怎么处理 |

长表（码值、字段枚举）放 `reference/`，正文只引用。Skill 不实现 HTTP，只教怎么调 CLI。

---

## 提交（变更写清楚）

动到**命令名、参数、输出结构**等核心 I/O 时，同一 PR 必须：

1. **CHANGELOG** — 记改了什么、旧用法还能不能用
2. **README** — 同步示例和字段说明
3. **SKILL.md** — 同步命令表、意图映射、权限边界

---

## 环境无关（不绑本机）

CLI 要能在**别人的机器、平台容器**上直接跑，不能只在你电脑上能跑。

| 要做 | 不要 |
|------|------|
| `pyproject.toml` 注册命令，`pip install` / `pip install -e .` 后全局 `horae --help` 可用 | 依赖 `python -m horae.cli`、`py -3 horae/...`、必须先 `cd` 到仓库目录 |
| 依赖写进 `pyproject.toml`，装包时一并装上 | README 里写「先手动 pip install xxx」却不声明依赖 |
| 凭据、base_url 等走 env 或配置文件，有合理默认 | 写死 `C:/Users/...`、`D:\work\...`、某人本机路径 |
| 上平台多人用时，**额外**支持 env 凭据（如 `HORAE_COOKIE`） | 只能本机浏览器弹窗登录，容器里跑不了 |
| 发版前在**干净环境**验证：`clone → pip install → 跑一条只读命令` | 只在当前 venv / 当前 IDE 里测过就算完成 |

本机开发可以用 CDP 登录等便利方式，但**不能成为唯一认证路径**。
